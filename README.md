# کارمَن | مدیریت زمان و درآمد

نسخه اولیه اپلیکیشن مدیریت ساعات کاری، درآمد و هزینه‌ها با React و JavaScript.

## امکانات پیاده‌سازی‌شده
- داشبورد موجودی کیف پول و گردش مالی بازه‌ای (این هفته، این ماه، از ابتدا)
- شروع و پایان نوبت کاری و بازیابی تایمر بعد از بسته‌شدن برنامه
- محاسبه درآمد با دقت دقیقه و نرخ ذخیره‌شده برای هر نوبت
- تأیید درآمد پیش از اضافه‌شدن به کیف پول
- ثبت درآمد متفرقه و هزینه/برداشت همراه عنوان، توضیح و تاریخ
- آرشیو، فیلتر، ویرایش و حذف سوابق با اصلاح خودکار موجودی
- ذخیره محلی اطلاعات با IndexedDB
- رابط فارسی و راست‌چین

## پیش‌نیازها
- Node.js نسخه 20 یا جدیدتر
- برای ساخت APK: Android Studio و JDK 17

## اجرا در کامپیوتر
```bash
npm install
npm run dev
```

## ساخت نسخه وب
```bash
npm run build
```
خروجی وب در پوشه `dist` ساخته می‌شود و می‌توان آن را روی هاست استاتیک منتشر کرد.

## آماده‌سازی اندروید
```bash
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
```
سپس در Android Studio پروژه را Build کن. برای دفعات بعد از تغییر کد وب، `npm run build` و `npx cap sync android` را اجرا کن.

## نکات نسخه اولیه
- اطلاعات فقط روی همان دستگاه/مرورگر ذخیره می‌شود؛ پاک‌کردن داده‌های برنامه یا مرورگر می‌تواند اطلاعات را حذف کند.
- همگام‌سازی ابری، حساب کاربری و پشتیبان‌گیری خودکار در این نسخه وجود ندارد.
- تاریخ‌ها در داده‌ها با زمان استاندارد ذخیره و در رابط با تقویم شمسی نمایش داده می‌شوند. ورودی تاریخ در فرم‌ها ممکن است ظاهر میلادی سیستم را داشته باشد.
- قبل از استفاده واقعی مالی، تست روی دستگاه هدف و بررسی سناریوهای زمانی ضروری است.
